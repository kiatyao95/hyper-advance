# Hyper Advance

Corporate website for Hyper Advance Sdn Bhd — ELV contractor and authorised distributor in Malaysia.

## Stack

React + Vite. Site source lives in `v4/`.

## Local development

```bash
npm install --prefix v4
npm run dev --prefix v4
```

Local dev: http://localhost:5173/

Production build:

```bash
npm run build --prefix v4
```

## Live site

**URL:** https://www.hyper-advance.com/

After pushing to `main`, GitHub Actions builds `v4` and publishes it to the `docs/` folder (see `.github/workflows/deploy-v4.yml`).

## Repository layout

- `v4/` — React + Vite site source (primary)
- `docs/` — Published build output served by GitHub Pages. Generated by CI — do not edit by hand.
- `design-system/` — Design system reference for the site
- `.github/workflows/deploy-v4.yml` — Build & deploy pipeline
